For the auxiliary readout and support-budget comparisons, the gate grid is $a,u\in\{0,0.25,0.5,1,2\}$ and $d\in\{-2,-1.5,\ldots,2\}$. Offset-calibrated controls use their separately stated grids. \subsection{Readouts and evaluation measures}
All compared readouts use the same CLIP image embeddings, text anchors, class partitions, and novel support images. The text baseline uses cosine similarity to class names. The visual prototype baseline uses means of base fitting examples and means of novel support examples. Text--prototype fusion adds the two cosine branches with a mixing coefficient selected on the same pseudo-novel calibration episode; its grid is $\{0,0.25,0.5,1,2,4\}$, including pure text.

Tip-Adapter uses a balanced $k$-image cache per candidate and scores $100q_T+\alpha q_{\mathrm{cache}}$, with affinity $\exp[\beta(v^\top f(x_i)-1)]$. The same base-only episode selects $\alpha\in\{0,0.5,1,2,4\}$ and $\beta\in\{1,2,5,10\}$. Cache images come from the reserved pool for both groups; base-trained readouts use the full base fitting set.

We also compare raw evidence fusion and candidate-normalized fusion. Raw fusion uses unstandardized text, learned, and prototype scores with the same coefficient grid as the proposed table. Candidate-normalized fusion standardizes text over all active classes, learned scores over the base classes, and prototypes over active novel classes. It shares the base classifier and calibration protocol with reference-anchored fusion. This comparison changes the normalization population while holding the principal evidence sources fixed.

We report macro base accuracy $A_B$, macro novel accuracy $A_N$, all-class macro accuracy, and the harmonic mean in Eq.~\eqref{main-eq:harmonic}. Both datasets use equal numbers of base and novel classes, so all-class macro accuracy is $(A_B+A_N)/2$. On the balanced CIFAR test set this also equals sample accuracy; on Pets the macro measure gives each breed equal weight. Stability measures include maximum absolute change in an existing score, change of the maximizing class restricted to base classes, and prediction changes over the expanded vocabulary. Error flips are reported as fractions of all base test images, not conditional fractions of previously correct images.

\section{Reproduction details}
\label{app:reproduction}
The expansion experiment is implemented in \nolinkurl{src/experiments/fcs_expansion.py}. It can be run from any working directory. The manifest records the code hash, frozen-cache hash, image-pool hashes, class assignments, pseudo-class assignments, support indices, regularization choices, and selection grids. The frozen support features are computed with the same deterministic interpolation used for the frozen training cache. The cached image embeddings are checked numerically before scoring.

Every novel support image comes from the five-image-per-class reserve created before long-tail sampling. This supplies a consistent support budget even for tail classes whose fitting pool contains fewer than five images. At five shots the three subset seeds select the same images in different orders, so the reported standard deviation is calculated across the three distinct class partitions. One- and two-shot results average the three subsets within each partition before computing the partition-level variation.

The main result JSON contains all compared readouts, including evidence-removal ablations. The vocabulary records contain the maximum score drift and both restricted and expanded prediction churn. The operating-curve records contain every swept offset, with no selection based on test outcomes. The efficiency records specify batch size and measured vocabulary size. The manuscript tables are generated directly from these files, and the summary CSV exposes both means and sample standard deviations.

The semantic prompts are ``a photo of a \{\}.'', ``a bad photo of a \{\}.'', ``a cropped photo of a \{\}.'', ``a close-up photo of a \{\}.'', ``a bright photo of a \{\}.'', ``a good photo of a \{\}.'', ``a photo of the \{\}.'', and a second occurrence of ``a photo of a \{\}.''. The repeated prompt follows the existing cached anchor construction and is retained consistently for all methods.

Frozen CLIP features are the sole image representation in the expansion experiments. Six fitting images are independently re-embedded and checked for cosine agreement above 0.999 with the cached features. Image hashes verify that fitting, validation, and reserved-support pools are disjoint. The fixed base text block is computed separately from novel text columns; sequential prototype products can exhibit the reported floating-point residuals when matrix widths change.

\section{Interpreting group competition}
Let $M_B(x)=\max_{b\in\mathcal B}[\widehat q_T(x,b)+a\widehat q_L(x,b)]$ and $M_N(x)=\max_{n\in\mathcal N}[\widehat q_T(x,n)+u\widehat q_P(x,n)]$. The classifier selects a novel class precisely when $M_N(x)+d>M_B(x)$, subject to the fixed tie-breaking rule. Hence, the offset is a threshold on the margin $M_B-M_N$. Increasing $d$ cannot change the winning base class or the winning novel class when all other quantities are fixed. It changes which group supplies the final winner. This explains the direction of the operating curves without assuming a calibrated probability interpretation for the fused score.

For nested candidate sets and fixed references, adding novel rows can increase $M_N$ but cannot change $M_B$. An existing-class example may therefore cross the admission boundary as the vocabulary grows, while its base scores remain identical. This distinguishes the deployment behavior measured by expanded prediction churn from the normalization behavior measured by base-only ranking churn.

\subsection{Exact empirical retention envelope}
For a fixed readout, let $b_i$ and $n_i$ be the canonical winning base and novel
class for query $i$, and let $\Delta_i=M_B(x_i)-M_N(x_i)$. Define
$g_i(d)=\mathbf 1[d>\Delta_i\ \text{or}\ (d=\Delta_i\ \text{and}\ n_i<b_i)]$.
With the class-macro weights $w_i$, the two group accuracies are
\begin{align}
 A_B(d)&=\sum_{i:y_i\in\mathcal B}w_i\mathbf 1[b_i=y_i](1-g_i(d)),\\
 A_N(d)&=\sum_{i:y_i\in\mathcal N}w_i\mathbf 1[n_i=y_i]g_i(d).
\end{align}
Thus $A_B$ is nonincreasing and $A_N$ is nondecreasing in $d$.
For the stored finite-precision scores, an exact search need only consider each
observed margin and its immediately preceding representable offset, together
with the all-base and all-novel endpoints. Between adjacent margins every group
decision is fixed. If $\tau$ exceeds
$\sum_{i:y_i\in\mathcal B}w_i\mathbf 1[b_i=y_i]$, the constraint is infeasible.
Otherwise, sorting the margins of correctly classified base queries in descending
order and accumulating their macro weights locates the boundary at which retained
base mass first reaches $\tau$. The tie rule selects that boundary or its
predecessor. This is the largest feasible offset in the implementation's offset
ordering. Monotonicity of $A_N$ proves that it maximizes novel accuracy under the
empirical constraint. The argument applies identically to base-validation
selection; that policy's test outcome is evaluated on separate queries.

The envelope separates the within-base feasible ceiling, the admitted group
threshold and the distribution of correctly classified novel-query margins.
It therefore measures the joint operating value of a learned readout and its
competition with arriving evidence, beyond the statement that stored scores
are preserved.

\section{Additional background and score-preservation proof}
\subsection{Long-tailed recognition and calibration}
Long-tailed recognition addresses the bias induced by unequal class frequencies. Margin adjustment allocates different classification margins to frequent and rare classes~\cite{cao2019ldam}; class-balanced weighting uses effective sample counts~\cite{cui2019classbalanced}; and prior-aware objectives modify the relationship between logits and class probabilities~\cite{ren2020bsm,menon2021logitadj}. Representation--classifier decoupling provides a complementary route: a representation is learned first and a balanced classifier is then fitted to that representation~\cite{kang2020decoupling}. These developments motivate our use of a balanced base classifier as one source of evidence.

Foundation models change the representation-learning budget and the role of task-specific adaptation. LIFT studies lightweight adaptation of pre-trained models for long-tail learning~\cite{shi2024lift}. Low-rank updates provide an efficient mechanism for adapting large parameter matrices~\cite{hu2022lora}, including transformer backbones~\cite{dosovitskiy2021vit}. Our candidate interface can accept weights obtained through these routes. The expansion experiments here fix the encoder throughout and isolate the effect of the readout.

Long-tailed calibration studies confidence under class imbalance~\cite{zhong2021mislas}, while robust long-tailed learning addresses its interaction with label noise~\cite{wei2026robust}. We study the reference population used to standardize evidence as candidate classes change. Class-balanced validation and separate base/novel metrics expose how the resulting score system allocates discrimination.

\subsection{Semantic and visual evidence for few-shot recognition}
CLIP constructs classifiers from natural-language supervision and supports classification by changing the text candidates~\cite{radford2021clip}. CoOp learns prompt context for target tasks, while CoCoOp introduces conditional prompting to improve transfer across categories~\cite{zhou2022coop,zhou2022cocoop}. These methods concern the construction or adaptation of semantic evidence. Our table keeps semantic anchors available to every class and combines them with evidence that may exist for only a subset of the vocabulary.

Prototype methods summarize class examples in an embedding space~\cite{snell2017prototypical}. SimpleShot studies feature normalization for nearest-neighbor classification~\cite{wang2019simpleshot}, and Tip-Adapter augments CLIP with a support-feature cache~\cite{zhang2022tipadapter}. Few-shot transfer under distribution shift further motivates separating shared and task-specific knowledge~\cite{zhu2023combat}. Our comparisons use a shared encoder and novel support budget to examine evidence availability and its normalization reference.

\subsection{Proof of the main score-preservation proposition}
\begin{proof}
For an existing candidate $c$, each raw score $q_e(x,c)$ and mask $m_{ec}$ is fixed. The means and variances in Eq.~\eqref{main-eq:reference} are functions of $x$ and $\mathcal R_e$, and neither depends on the appended rows. Therefore each normalized score in Eq.~\eqref{main-eq:anchored} is unchanged. The coefficients and offset of $c$ are fixed, so their sum is unchanged. Subtracting the unchanged scores of any two existing rows gives an unchanged difference. A fixed tie-breaking rule preserves the maximizing existing row.
\end{proof}

The proposition covers both base rows and previously appended novel rows with fixed prototypes. The implementation computes the fixed base text block separately from novel columns to keep its numerical kernel independent of the appended width.

\begin{corollary}
If every existing row has a preserved score, a changed final prediction after expansion must select an appended row. An example whose previous prediction was incorrect cannot become correct after adding classes when its true class belongs to the existing vocabulary.
\label{cor:competition}
\end{corollary}
\begin{proof}
The best existing row is unchanged by Proposition~\ref{main-prop:invariance}. The expanded maximizer is either this row or a newly appended row. For an example labeled by an existing class, selecting a new row cannot correct a previous error, and keeping the existing maximizer leaves the previous error unchanged.
\end{proof}

\section{Recent readout comparison and ImageNet-R extension}
The extension protocol was recorded before ImageNet-R evaluation. Class partitions use seeds 0, 1 and 2, with exact frequency-stratified allocation of 100 base and 100 novel classes. Within each base group, seed $900+p$ assigns 50 pseudo-base and 50 pseudo-novel classes. Base-only validation selects ridge regularization, branch mixtures and readout hyperparameters. No ImageNet-R test result selects these quantities. The retained table, removal controls and dense prototype replacement use the same grids as the CIFAR/Pets experiment.

FeNeC~\cite{ksiazek2026fenec} is independently implemented from the paper's equations and checked against author-code commit \nolinkurl{1575ea019fd583149c47c068f7f5ccc102ea4580}. Both variants use identity Tukey transformation for signed CLIP features and Euclidean k-means with a maximum of 100 iterations. The representative grid is $K\in\{1,5,25\}$ and the neighbor grid is $\{1,3,5\}$. FeNeC-M estimates one covariance per class, applies the author's ViT single-shrinkage and correlation normalization with $(\gamma_1,\gamma_2)\in\{(1,1),(6.12,8.10),(9.98,0)\}$, then uses inverse squared-Mahalanobis-distance votes. FeNeC-E uses inverse unsquared-Euclidean-distance votes. Their native predictions are preserved when votes are converted to log votes, with a floor of $10^{-30}$. The calibrated forms select a novel offset from $[-4,4]$ in steps of 0.25 on the pseudo episode. Harmonic macro accuracy chooses the configuration.

The five-shot protocol caps a class's representative count at its sample count. A class with one fitting sample uses identity covariance, avoiding an undefined sample covariance. These are explicit sparse-data adaptations. A per-class independent summary can be cached before its arrival; the voting neighborhood always contains only currently admitted classes. Native and calibrated forms share each current-vocabulary score matrix, so their complete matched-retention frontiers coincide, while fixed-offset trajectories can differ. The final grids are documented with the code. FeNeC frontiers use its sparse global-neighbor votes, with unvoted classes at the common floor; feasibility refers to this output interface.

All ImageNet-R images are content-hashed before pool assignment. Fifty-nine byte-identical duplicates are removed globally. No retained content hash appears in two fitting, validation, support or test pools. The source archive has SHA-256 \nolinkurl{18c6bf493b39a0d975d48e587437f562caab9c52ae6327dcfa9dd8eb54aa1b52}. The class-name mapping, image paths, achieved fitting counts, source hashes, calibrated settings and prediction margins accompany the code and records. These are task-specific splits of ImageNet-R, whose source release is a rendition benchmark~\cite{hendrycks2021manyfaces}.

\section{Dense caches, repeated calibration and measured readout cost}
\label{app:depth}
\subsection{Dense semantic-cache protocol}
The training-free Tip-Adapter score follows the ECCV paper and the author
implementation~\cite{zhang2022tipadapter}: cosine similarity to labeled cache keys
is transformed by $\exp[-\beta(1-\mathrm{similarity})]$, summed into classes and
added to $100$ times text similarity with weight $\alpha$. The author code is
pinned at commit \nolinkurl{d0e2d6f8c5feb8b6ce937b757810761f7155d4d5}.
All permitted base fitting images and five reserved novel support images supply
the keys. The sum variant retains the published aggregation. A separate
class-mean variant divides each class's retrieval score by its key count,
isolating the effect of unequal long-tailed cache sizes. Both reuse the same
single-view frozen features and text anchors as the tables. This comparison
transfers the published readout under controlled feature access; the original
augmented-cache extraction and trainable Tip-Adapter-F are distinct settings.

\label{app:independentrisk}
\subsection{Disjoint access and refitting}
For each dataset, original fitting and validation features are concatenated in that order. Only frozen features are reused; previously tuned score models are not treated as independent of their old validation labels. The new calibration labels enter only threshold certification or the explicitly compared empirical threshold controls. The independent-pool experiment is a benchmark revision on previously studied test data, not a newly untouched final evaluation. The statistical analysis assumes that, conditional on each base class and the fitted models, calibration observations are independent draws from the class-conditional distribution to which the population statement applies. Dataset shift and adaptive support arrivals depending on calibration labels are outside that statement.

\subsection{Weighted protection bound}
Let $B$ be the number of base classes and $n_c$ their calibration counts. Assign each observation of class $c$ weight $w_i=1/(Bn_c)$, so $\sum_iw_i=1$, and let $b=\max_iw_i$. For any fixed bounded losses $L_i\in[0,1]$, write $q=\sum_iw_iL_i$ and $\mu=\sum_iw_i\mathbb E L_i$. Conditional on the score models and the independently selected threshold family, independence gives, for $t<0$,
\begin{align}
 \log\mathbb E e^{tq}
 &\leq\sum_i\log(1-\mu_i+\mu_i e^{tw_i})\\
 &\leq b^{-1}\sum_iw_i\log(1-\mu_i+\mu_i e^{tb})\\
 &\leq b^{-1}\log(1-\mu+\mu e^{tb}),
\end{align}
where $\mu_i=\mathbb E L_i$. The first inequality uses boundedness and the chord of the exponential; the second uses convexity of each log-moment-generating function in $w_i$ and its zero value at zero; the third uses concavity in $\mu_i$. Chernoff optimization yields
\begin{equation}
 \Pr(q\leq x)\leq\exp[-\operatorname{kl}(x,\mu)/b],\qquad x<\mu,
\end{equation}
where $\operatorname{kl}$ is Bernoulli relative entropy. Thus, for the null $\mu\geq\alpha$, the value
\begin{equation}
 p(q)=\begin{cases}
 \exp[-\operatorname{kl}(q,\alpha)/b],&q<\alpha,\\
 1,&q\geq\alpha
 \end{cases}
\end{equation}
is a valid lower-tail p-value. Unlike an ordinary pooled binomial calculation, this bound retains the unequal macro weights. Its dependence on the largest weight makes sparse class-conditional calibration sets conservative.

Apply the bound to the protection loss of main Eq.~\eqref{main-eq:protectionloss}. Let $A_{\mathrm{ref}}=\Pr(R=1)$, $D=\Pr(R=1,C_d=0)$ and $G=\Pr(R=0,C_d=1)$. Then
\begin{equation}
 \mathbb E L_d=D+(1-r)(1-A_{\mathrm{ref}}),\qquad
 A_B(d)=A_{\mathrm{ref}}-D+G.
\end{equation}
Consequently $\mathbb E L_d\leq1-r$ implies $A_B(d)\geq rA_{\mathrm{ref}}$. The reference uncertainty is included in the paired loss rather than replaced by a point estimate. Retained base scores have $G=0$; other readouts may have $G>0$, so protection is sufficient and can be stricter than accuracy-ratio control for replacement models.

\subsection{Threshold search and trajectory confidence}
For each method and arrival, the independently fixed finite threshold family consists of unique quantiles at 0,1,\ldots,100\% of base tuning margins, in increasing order of novel admission. Following fixed-sequence testing~\cite{angelopoulos2021ltt}, test this family in order at level $\delta/5$, stop at the first failure, and return the last accepted threshold. A false certification requires rejecting the first true null in the fixed order, whose probability is at most $\delta/5$; independence between these tests is unnecessary. A union bound over the five prespecified arrivals gives error probability at most $\delta$ for each method/order/partition. The same calibration pool may be reused because the score models, threshold families and support arrivals do not adapt to its labels. No simultaneous confidence claim across methods, orders, partitions, datasets or separately reported $\delta$ values is made.

If the accepted finite set is empty, the policy returns the original reference classifier and admits no novel class. This fallback structurally preserves its original accuracy and has zero novel accuracy. It is reported separately from useful certified expansion. The confidence levels 90,95,99\% and empirical target fractions 95,97,99\% were specified before the new experiment; the primary setting uses 95\% retention and 95\% confidence. Their complete results, worst shortfalls and five-session trajectories are saved in \nolinkurl{independent_risk_summary.json} and \nolinkurl{independent_risk_summary.csv}.

\subsection{Dataset construction and access}

We evaluate expansion on CIFAR-100~\cite{krizhevsky2009cifar} with long-tailed base supervision. The training class counts follow an exponential schedule with imbalance parameter $\rho=100$ and nominal maximum 500 images. Five images per class are reserved before constructing the long-tailed pool, so the largest available pool contains 495 images. The remaining long-tailed pool contains 10,894 images, split into 10,487 fitting images and 407 held-out validation images. Validation reserves up to five examples per class, with smaller allocations for the rarest classes.

For seeds $\{0,\ldots,9\}$, stratified sampling within head, medium, and tail frequency buckets yields distinct partitions of 40 base, 40 novel, and 20 unused classes. Proportional quotas use largest-remainder rounding after shuffling class membership. Evaluation uses the 80 base and novel classes.

Oxford-IIIT Pets~\cite{parkhi2012cats} provides a complementary fine-grained task with 37 cat and dog breeds. We use its official trainval/test split and reserve five training images per breed as support. From the remaining training images, we construct an exponential long-tailed pool with $\rho=10$ and maximum class count 90, giving 1,168 fitting and 146 validation images. Each true partition contains 15 base, 15 novel, and seven unused breeds, sampled with the same allocation rule. The official test split contains 3,669 images. Unlike CIFAR, its images have varied spatial resolutions; RGB images are resized to $224\times224$ by PIL bicubic interpolation before the same CLIP normalization. These features are freshly extracted for this study.

All primary expansion readouts use frozen OpenAI CLIP ViT-L/14 or ViT-B/32 features from a single $224\times224$ bicubic-resized image with CLIP channel normalization. Fitting, validation, and support pools are disjoint. Supplementary Section C gives feature-cache and image-pool verification details.

Base ridge regularization is selected from $\{0.01,0.1,1,10\}$ by base validation macro accuracy; the pseudo-base classifier uses the same rule. The primary comparison uses all five reserved support images, ten distinct class partitions and two arrival orders per partition. Earlier one/two/five-shot and repeated-calibration studies use three original partitions and are reported separately in Supplementary Section G.

Classifier fitting, regularization selection, and gate calibration use base classes exclusively. Five-shot CIFAR expansion consumes 200 support images for 40 novel classes. Its balanced test set supplies 4,000 base and 4,000 novel images for the expanded metrics.

ImageNet-R~\cite{hendrycks2021manyfaces} extends the active vocabulary to 200 rendition classes: 100 base classes followed by five arrivals of 20 classes. After removing 59 byte-identical duplicates, per-class seeded splits reserve approximately 20\% each for validation and test, then five support images. The fitting pool is downsampled by class rank with a nominal 100:1 schedule, yielding 2--136 images per class after availability caps. The resulting pools contain 6,438 fitting, 5,911 validation, 1,000 support and 5,911 test images. Ten frequency-stratified class partitions and two arrival orders use the same selection and reporting rules as the other datasets. RGB images are resized to $224\times224$ with bicubic interpolation and encoded by the same selected frozen checkpoint within each encoder comparison.

The ridge readout uses an augmented constant feature, inverse-frequency sample weights and an unregularized intercept; only the feature slopes receive ridge regularization. Class prototypes are normalized means of the permitted fitting or support features.

\subsection{Pseudo-expansion selection}
Fusion calibration must respect the distinction between base supervision and novel support. We construct a pseudo-expansion episode by splitting the base classes into approximately equal pseudo-base and pseudo-novel groups: 20/20 on CIFAR-100, 7/8 on Pets and 50/50 on ImageNet-R. A separate classifier is fitted using the pseudo-base classes alone. The pseudo-novel rows contain names and $k$ support examples from those base classes, while held-out base validation images supply query labels. This episode simulates missing learned evidence without consuming any actual novel-class validation labels.

For each support budget, candidate coefficients are evaluated on this episode. The selection objective is the harmonic mean of macro accuracy on the two groups,
$H=2A_BA_N/(A_B+A_N)$
We set $H=0$ when both terms vanish. The calibration grids are $a\in\{0,0.25,0.5,1,2\}$, $u\in\{0,0.25,0.5,1,2,4\}$, and offsets $d\in[-4,4]$ in steps of $0.25$. Ties follow a fixed grid order. The full base classifier is then combined with actual novel rows using the selected coefficients. Neither actual novel validation queries nor test labels enter this selection rule.

This procedure uses one pseudo-class split per true partition and the same support-index seed as the evaluated support condition. CIFAR and Pets pseudo splits use seed $100+p$ for class-partition seed $p$; ImageNet-R selects half the base classes with seed $900+p$. Coefficients are chosen once for a support budget and stay fixed when the vocabulary-size stress test appends successive subsets of novel classes.

\subsection{A normalization example}
A two-class example illustrates the effect. Suppose the old text scores are $(0,2)$, giving standardized scores $(-1,1)$, while the learned branch contributes $(0.25,-0.25)$. The second old class has the larger fused score. Appending a text score of $100$ changes the two old standardized scores to approximately $(-0.728,-0.685)$. Their text separation is now about $0.043$, and the unchanged learned contribution reverses the old-class ordering. No classifier weight has changed. The example isolates a normalization effect independently of whether the new class ultimately wins the expanded decision.

\subsection{A necessary coverage condition for certification}
For the weighted bound in Section J, even $q=0$ gives
\begin{equation}
 p(0)=\exp[-\operatorname{kl}(0,1-r)/b]=r^{1/b}.
\end{equation}
Since $p(q)$ increases on $0\leq q<1-r$, passing at level $\delta/5$ requires
\begin{equation}
 n_{\mathrm{eff}}=1/b=B\min_c n_c\geq\frac{\log(\delta/5)}{\log r}.
\end{equation}
At $r=0.95$ and $\delta=0.05$, this floor is 89.78. It is a necessary condition for this certificate, not a sufficient condition for successful expansion. Under the original allocation, CIFAR has $n_{\mathrm{eff}}=80$, Pets has 45 or 60 and ImageNet-R has 600, 700 or 800. Thus the original CIFAR/Pets calibration allocation cannot pass this bound even at zero observed loss. Balanced per-class caps must be at least 3 for CIFAR, 6 for Pets and 1 for ImageNet-R to clear the zero-loss floor. Actual protection losses require further evidence. A balanced allocation can improve the bound even with fewer total labels than a larger, uneven pool.

\subsection{What centering changes algebraically}
Suppress the text-centering shift shared by every candidate. Define uncentered, scaled scores
\begin{align}
 B_b(x)&=q_T(x,b)/\sigma_T(x)+a q_L(x,b)/\sigma_L(x),\\
 N_n(x)&=q_T(x,n)/\sigma_T(x)+u q_P(x,n)/\sigma_P(x).
\end{align}
The centered decision admits novel if the group margin $\max_bB_b-\max_nN_n$ is below
\begin{equation}
 d_{\mathrm{eff}}(x)=d+\Delta(x),\quad
 \Delta(x)=a\mu_L(x)/\sigma_L(x)-u\mu_P(x)/\sigma_P(x),
\end{equation}
with the original tie rule and floored standard deviations. Query scales still affect within-group fusion. Fixing a nonzero center while retaining query scale does not generally make this effective offset constant.

The fitted ridge model imposes a further constraint. Its augmented design $X$ includes an unregularized intercept and one-hot targets $Y$. Since $Y\mathbf1=\mathbf1$ and the slope regularizer annihilates the intercept vector $e_0$, the normal equations imply
\begin{equation}
 (X^\top\Omega X+L)W\mathbf1
 =X^\top\Omega\mathbf1=(X^\top\Omega X+L)e_0.
\end{equation}
For the unique regularized solution, $W\mathbf1=e_0$ and $\mu_L(x)=1/|\mathcal B|$ in exact arithmetic. The learned contribution to $\Delta$ varies through its scale, not a freely changing learned-score mean. The prototype reference mean can vary with the query. Numerical and imbalanced synthetic checks are supplied with the code; they are not recognition benchmarks.

\subsection{Error structure and paired-score variance}
For a base query under the class-macro law, let $R,C\in\{0,1\}$ denote reference and expanded correctness, $A_R=\mathbb E R$, $A_C=\mathbb E C$, $D=\Pr(R=1,C=0)$, and $G=\Pr(R=0,C=1)$. The four joint events give
\begin{align}
 \mathbb E(C-rR)&=A_C-rA_R,\\
 \mathbb E(C-rR)^2&=(A_R-D)(1-r)^2+Dr^2+G\\
 &=A_R(1-r)^2+(A_R-A_C)(2r-1)+2rG.
\end{align}
Subtracting the squared mean proves main Eq.~\eqref{main-eq:pairedvariance}. Holding both accuracies fixed makes the variance difference between two couplings exactly $2r(G_2-G_1)$. A zero-recovery coupling exists when $A_C\leq A_R$; it minimizes variance among couplings with those accuracies. This is a comparison of correctness distributions at fixed margins, not a claim that every retained policy has smaller variance than every replacement policy at their different selected accuracies.

For independent class-stratified observations, let $A_{R,c}$, $A_{C,c}$ and $G_c$ be the conditional quantities. The identity holds within each class, and the calibration mean has variance
\begin{equation}
 \operatorname{Var}\!\left(\sum_i w_i Z_i\right)=\frac{1}{B^2}\sum_c\frac{\operatorname{Var}(Z\mid c)}{n_c}.
\end{equation}
If both accuracies match within every class, the weighted-mean variance difference is $2r B^{-2}\sum_c(G_{2,c}-G_{1,c})/n_c$. Matching overall macro accuracies alone does not imply this stratified comparison. The fixed-sample betting p-value also depends on the observed product, so variance order by itself is not a certification-power theorem.

The protection criterion has an additional exact relation. With $\alpha=1-r$,
\begin{equation}
 \alpha-\mathbb E L=A_C-rA_R-G.
\end{equation}
Thus preservation ($G=0$) makes protection equivalent to the accuracy target. For replacement readouts, the direct test credits the recovery term rather than discarding it. These algebraic results explain the error-structure role separately from the empirical capacity-to-policy decomposition.

\subsection{Error destinations and verification scope}
For base queries, $A_B=A_{\mathrm{ref}}-D+G$ uses the same reference for every readout. $D$ contains losses to novel labels and losses to another base label. With retained base scores, within-base ranking cannot change, so $G=0$ and destruction to another base class is zero. A replacement readout can have both error destinations and can recover reference errors. \label{app:sketchvalidation}
\subsection{Outcome-blind acquisition and identity separation}
ImageNet-Sketch~\cite{wang2019robustglobal} supplies a natural rendering distribution for the same ImageNet class vocabulary. The execution protocol, \nolinkurl{experiments/kbs_sketch_execution_protocol_v1.md}, was fixed before target features or recognition outcomes. The author-linked Hugging Face archive is pinned to revision \nolinkurl{0d8b8b5380efe50baae075842505918ad43c88fe}. Ranged acquisition retrieves the 200 ImageNet-R synsets, with 10,152 image entries and CRC-checked payloads, without downloading the full archive.

Identity checks compare raw bytes and resized 224-RGB pixels against all 22,280 used source fitting, tuning, support, calibration and test paths. They remove 3,624 source-byte overlaps. Target checks additionally remove eight raw duplicates, 62 pixel duplicates and 13 exact rotation/flip equivalents, leaving 6,445 images across all 200 classes (22--50 images per class). Rotation/flip grouping uses the eight square dihedral transforms. Exact fingerprints do not rule out all near-duplicates or establish absence from CLIP pre-training.

Before encoding, seed 27102026 reserves $\min(20,\max(1,\lfloor .4n_c\rfloor))$ images per class for calibration and the remainder for test, giving 2,492 calibration and 3,953 test images. Source-calibration subsets have identical per-class counts to Sketch calibration, selected without scores. Each partition uses 1,233--1,260 base calibration queries. Every method shares these identities. Local CLIP weights and source PIL224 preprocessing are reused; source-image witness encodings verify feature-space agreement before target embedding. Features are saved in resumable batches of at most 16 images.

\subsection{Fixed source models and calibrated admission}
The primary study transfers the original source-selected retained, dense-prototype and HyCal readouts. It is separate from Section Q's fusion re-selection. The original ten partitions, first arrival order, five sessions, source five-shot support, ridge fits, fusion coefficients and HyCal regularization remain fixed. Candidate offsets are copied from the source-tuning archives. No Sketch labels tune these quantities. Only independent calibration selects the admission offset, using either source or Sketch queries with identical class-wise counts. Both statistical criteria retain $r=.95$, $\delta=.05$ and the five-session allocation for each fixed method/partition/calibration/policy.

With Sketch calibration, the retained readout admits all five sessions and meets every empirical test target in all ten paths for each encoder and criterion. The direct policy reaches 86.82\% novel accuracy at 90.76\% base accuracy with L/14, and 58.96\% at 78.87\% with B/32 after the fifth arrival. Source calibration also admits all retained paths and meets their targets; its final direct novel accuracies are 82.99\% and 54.87\%. Here target-matched calibration increases admitted novel recognition rather than repairing observed source-calibration target violations.

Tables~\ref{tab:sketchl14} and~\ref{tab:sketchb32} include all three readouts and both criteria. For direct target calibration, dense L/14 admits all ten partitions at 83.34\% novel accuracy. Dense B/32 admits three, with fallback-inclusive/conditional novel accuracy 8.35\%/27.84\%. HyCal L/14 admits two, with 10.47\%/52.34\% novel accuracy and one final test-target miss; HyCal B/32 returns reference fallback throughout. Thus fallback, admission and empirical target attainment are reported separately.

\subsection{Descriptive capacity and scope}
Table~\ref{tab:sketchcapacity} and Figure~\ref{fig:sketchfrontiers} distinguish attainable recognition from calibrated operating points. At the common 95\% minimum target, L/14 retained and dense capacities average 88.84\%, with a paired difference of 0.001 [$-0.64$,0.69] points over ten jointly feasible partitions. With B/32, retention adds 5.78 [4.03,7.55] points over dense prototypes on nine jointly feasible partitions. These comparisons do not identify selected-policy gaps with intrinsic classifier gains. Full trajectories for all partitions and the original five retention levels accompany the summary.

The 2,700 metric records and 4,899 calibration tests are reconstructed from prediction archives, with unchanged source selection and candidate hashes. Population confidence retains independent class-conditional sampling and calibration--target correspondence assumptions; empirical success on these fixed target images is not a guarantee for arbitrary shifts or a simultaneous confidence statement over all configurations. Source-calibrated policies carry a source-law guarantee. Intervals describe assignment variation conditional on the fixed target images.
