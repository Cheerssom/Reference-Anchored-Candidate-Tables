# Full fusion retuning protocol — locked before new outcomes, 2026-10-26

This is a new controlled analysis on previously examined benchmarks, not an external preregistration. No new benchmark outcomes are inspected before this protocol is written.

- Reuse the original six dataset/encoder conditions, ten class partitions, two five-arrival orders, frozen features, original ridge fits/regularization choices, original five-shot supports and disjoint fitting/tuning/cap40 calibration/test roles. All stages use the existing local runtime, two CPU threads, serialized GPU and atomic checkpoints; honor experiments/kbs_strengthening/PAUSE.
- Cross readout (retained linear base evidence; dense visual-prototype base evidence) with normalization (query centering/query scaling; no centering/query scaling; fixed base-tuning mean/fixed base-tuning scale). Text and novel prototype branches follow the same normalization scheme. Base visual/linear coefficient a and novel prototype coefficient u are independently selected for EVERY scheme on the same grid {0,.25,.5,1,2,4} squared. Dense has separately tunable base/novel coefficients, a stronger control than the previous tied-coefficient dense baseline.
- Every scheme receives 36 coefficient pairs and101 offset quantiles per pair, computed from base-only pseudo-expansion tune margins including pseudo-base and pseudo-novel classes. Quantiles use np.linspace(0,1,101); duplicates still count toward the3636 evaluated budgets. Choose maximum pseudo harmonic macro accuracy, breaking ties by first coefficient pair, then first quantile index. This adapts offset ranges to branch scales without favoring query normalization. Record all trials and the selected coefficients before any calibration or test evaluation. The original ridge lambda and encoder remain fixed; this is full FUSION hyperparameter retuning, not all model architecture parameters.
- Fixed moments are mean reference score and mean query standard deviation estimated on original base-tuning queries, with the current pseudo-base or full-base reference bank, never using calibration or test queries. Reuse each selected coefficient pair through all arrivals.
- Keep the ORIGINAL independently fitted retained reference table and original a as a COMMON accuracy target/fallback for every scheme, r=.95. Full fusion retuning may change within-base rankings relative to this common original reference. Therefore G=0 is NOT asserted for this retuned study. Score persistence concerns a fixed selected model across appended rows.
- Independently fixed deployment candidate offsets are101 quantiles of FULL-BASE TUNING margins, using no novel-query labels. Same cap40 calibration images, fixed-sequence stopping, protection and direct paired tests, delta=.05/5 per session. Never select a certificate using test outcomes. Reference fallback gives zero novel accuracy. Report empirical target attainment, finite admission, conditional novel accuracy and fallback-inclusive policy outcomes.
- Compute exact descriptive matched-test capacities at .80/.85/.90/.95/.99 times the COMMON original reference's closed-base accuracy; these test-label oracles are not deployable thresholds. Report joint feasibility and conditional paired intervals; orders averaged within partition for primary paired comparisons, order0 final details also retained.
- Save per-partition selection/trials, per-session compact prediction archives, all selected policies and error destinations. Independently reconstruct selection maxima, calibrated stopping and reported predictions before manuscript integration. Restart completed stages without rewriting checkpoint files. No outcome-dependent grid or data-pool changes. Any amendment requires a new version/run directory before further outcomes.
