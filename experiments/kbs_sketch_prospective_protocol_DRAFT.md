# Prospective ImageNet-Sketch validation draft — NOT EXECUTED

This is an execution-ready design draft, not an externally registered protocol or completed external evaluation. Freeze a versioned manifest before feature extraction or inspecting recognition outcomes. Existing source-domain outcomes are already known.

1. Use only the published ImageNet-Sketch data from the author repository https://github.com/HaohanWang/ImageNet-Sketch . Map its ImageNet1K synsets to the existing ImageNet-R200 task using the saved source class index. Preserve the original ten base/novel assignments, frozen ridge models, CLIP checkpoints, source-domain supports and all selected fusion/HyCal parameters. Do not obtain target novel supports or tune on Sketch labels.
2. Before encoding, inventory actual target files and source pool hashes. Remove exact raw and resized224RGB pixel duplicates against all original fit/tune/support/calibration/test roles. Record any remaining near-duplicate limitation; absence of exact overlap does not establish stochastic independence. Publish synset mapping, identity exclusions and per-class availability before outcomes. If a required class has fewer than two usable images, stop and report the unavailable full-task evaluation instead of silently changing partitions.
3. Per class, with seed27102026, reserve min(20,max(1,floor(.4*n))) target images for calibration and all others for test. Every method shares these images. Source-calibration and target-calibration comparisons must use identical per-class calibration counts, capped by both available source and target pool sizes; source subsets are selected without score inspection. This separates sampling-budget changes from query-law correspondence.
4. Main conditions are both L/14 and B/32, retained/dense/HyCal readouts, ten partitions and order0 over all five arrivals. Reuse source model selections and support indices. Test protection and direct paired accuracy policies separately at r=.95 with delta=.05 split over five prespecified sessions per fixed method/order/partition/policy. No post-test certificate selection or simultaneous grid guarantee. If no finite threshold passes, use recorded reference fallback.
5. Report actual base/reference accuracy, retained fraction, finite admission, test-target attainment, fallback-inclusive novel accuracy and conditional novel accuracy. Give class-coverage counts and all-session path counts. Source-calibrated failures under shift and target-calibrated fallback are retained outcomes. The theoretical guarantee remains conditional on independent calibration observations and target-law correspondence; finite test success does not prove a universal coverage statement.
6. Effective-bias ECDFs and group-margin ranking are exploratory diagnostics, not tuning objectives. Compare complete frozen-readout trajectories at common achievable targets with explicit infeasibility and no interpolation. Do not assume bias orientation, monotonic gain, superiority on every class, or a causal texture/shape explanation.
7. Use existing local weights and identical PIL224bicubic preprocessing to the source ImageNet-R cache. Verify source witness encodings before new target embeddings. Encode only mapped target images, small batches with OOM halving; save atomic batch shards and per-session results. Shared PAUSE marker and two CPU threads remain active. Estimate download/storage requirements from the actual author asset before acquisition and retain a free-space margin. No paid compute or additional model checkpoint download.

The target data may overlap CLIP pretraining. Describe it as a new task-level natural-shift evaluation, not guaranteed unseen pretraining data or a previously unimagined domain. Do not change the protocol to favor observed outcomes; any availability amendment must be versioned before prediction.
